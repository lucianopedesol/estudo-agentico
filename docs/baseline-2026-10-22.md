## Leitura

### Tamanho do PR — mediana 46 linhas (bom, e é o número mais sólido aqui)

Lote pequeno é uma das sete práticas que a DORA associa a ganho real com IA.
Mediana de 46 linhas significa que as PRDs estão sendo quebradas no tamanho certo.
É a métrica para defender quando o volume subir: se a mediana começar a crescer,
a causa é PRD mal quebrada, não agente pior.

O máximo de 427 é quase certamente um PR de harness (workflow ou scaffold), não
de feature — vale confirmar qual foi, para saber se o teto é estrutural ou escapou.

### Retrabalho — 0.33 (alto, mas inflado de propósito)

Um em cada três PRs gerou correção depois. Num projeto normal seria alarme; aqui,
esses 5 commits são as lições documentadas no guia — config de ESLint faltando,
lockfile dessincronizado, output multi-linha da matrix, branch órfã da wave.
Quebrar coisas **era** o objetivo do laboratório.

Consequência prática: **não use 0.33 como meta de comparação.** O número honesto
para comparar é o da primeira semana do piloto real, com a equipe.

### Tempo até merge — 0.0h (não mede nada ainda)

Mediana e média zeradas significam que todos os 15 PRs foram mergeados em menos de
três minutos. Isso não é velocidade de entrega, é um dev solo abrindo e mergeando
o próprio PR em sequência. A métrica só passa a significar algo quando existir
alguém esperando do outro lado.

### Escrutínio — 93% (provavelmente artefato)

Este é o número que mais engana. 14 de 15 PRs com comentário ou review parece
excelente — mas combinado com os três minutos até o merge, não pode ser leitura
humana de código. Quase certamente está contando comentário automatizado ou
comentário do próprio autor no próprio PR, que não é revisão.

O contador precisa excluir o autor do PR para medir o que promete. Enquanto não
excluir, 93% é teto falso: quando a revisão de verdade entrar, o número vai
*cair*, e isso vai parecer regressão sem ser.

## Conclusão

Dois números valem como linha de base hoje — **tamanho do PR (46)** e, com
ressalva, **retrabalho (0.33)**. Os outros dois são propriedades de um
laboratório solo, não do fluxo.

A linha de base que vai valer para a equipe começa no primeiro dia do piloto com
os 3 devs. Rode de novo nesse dia e guarde ao lado desta.
